# DeckForge Roadmap

Status legend: ✅ shipped · 🚧 in progress · 📋 planned

## Shipped

- ✅ **Project generator** - the exact official Macro Deck plugin template, SDK pinned
  to 3.0.0-beta.14, verified end-to-end (build, validate, conformance, stub-host run).
- ✅ **Manifest Studio** - live typed editor + permissions + debounced validation.
- ✅ **Capability Gallery** - all 22 capabilities, docs deep links, scaffolding for
  Variables and Events into the open plugin.
- ✅ **Explorer** - workspace file tree.
- ✅ **Block Programmer (MVP)** - statement blocks → C# executors inside
  `macrodeck-blocks` markers with hand-code preservation.
- ✅ **Icon Studio (MVP)** - SVG templates, colors, WebView2 preview at 144/64 px.
- ✅ **Build & Run / Ship / Publish** - full artifact pipeline, Store Gate, release.yml
  writer, `gh release create`.
- ✅ **Terminal** - command console with history and streamed output.
- ✅ **Docs browser** - embedded WebView2 at docs.macro-deck.app.
- ✅ **Liquid design system** - Mica/Acrylic, elevation cards, 6 accents, light/dark/system.
- ✅ **QoL** - keyboard shortcuts (Ctrl+1..0, Ctrl+N/B/T/E/,, F1, F5), recents, environment
  doctor, crash log, About page.

## Also shipped (second wave)

- ✅ **Actions capability editor** - visual parameter design across all 29 editor types
  (range/choice/options/default/OnlyWhen data kept in the spec), localized labels, resx
  keys and PluginIntegration registration generated as a real action class.
- ✅ **Localization manager** - key list with default values, per-culture translation
  editor with (missing) markers, MDLOC diagnostics panel, add-key flow.
- ✅ **Widget Designer** - 21-node Macro Deck UI palette, node tree + properties,
  live 144px WebView2 tile preview, widget identity/config/flows options, generating a
  real IWidgetTypeProvider + IUiProvider provider file.
- ✅ **Block Programmer v2** - host-API blocks: user notifications and deck navigation
  join log/parameter/HTTP/delay/results, all cancellation-safe codegen.
- ✅ **Run & Debug console v2** - reserved-endpoint pokers (/_health /_ready /_info
  /_diagnostics) with automatic plugin-port detection from stub-host output.
- ✅ **Icon pack designer** - pack.json model with AI declaration, .macroDeckIconPack
  export, CLI icon-pack add bundling.
- ✅ **Text contrast fix** - WPF-UI TextFillColor* brushes overridden app-wide; white
  text everywhere, gray placeholders in text boxes.

## Also shipped (third wave)

- ✅ **Events editor** - configuration + payload parameter designers (same 29 editor
  types as Actions), category/optional fields, generating the IEventProvider definition
  into PluginIntegration.cs with resx keys and the events:publish permission.
- ✅ **Config Flow editor** - multi-step designer (step ids, titles, descriptions,
  instructions, links, OnlyWhen fields, validate-on-submit hooks, optional OAuth secret
  on complete) generating a real IConfigFlow class, Strings resx keys, host:config
  permission and the IConfigFlowProvider registration.
- ✅ **Widget Designer v2** - region switch (widget surface vs config surface),
  reorderable node tree (↑/↓), per-node events (press/long-press/change/... with
  Log/Publish-event/TODO handlers), button-state nodes, JSON Schema builder (typed
  properties, required, defaults), DesignerData-driven generated provider serving both
  surfaces.
- ✅ **Offline docs engine** - versioned snapshot of docs.macro-deck.app under
  %LOCALAPPDATA%/DeckForge/docs/<version>/ (sitemap-driven, ~125 pages + assets), served
  through a WebView2 virtual host mapping, Offline toggle, and full-text search with
  scored results and snippets.
- ✅ **Velopack packaging** - VelopackApp hooks in App startup, "Check for updates" in
  Settings (SimpleWebSource), and "Velopack releases" on Ship (dotnet publish + vpk pack:
  setup, portable, delta) with the app icon.
- ✅ **Executable icon** - multi-size app-icon.ico (256→16, PNG entries) generated by
  Assets/generate-icon.ps1 and compiled into DeckForge.exe via ApplicationIcon.
- ✅ **Black text on accent buttons** - AccentButtonForeground*/TextOnAccent* brushes
  forced to near-black in LiquidTheme for contrast on every Primary button.
- ✅ **Docs references everywhere** - Docs → buttons on Actions, Events, Setup Flow,
  Blocks (×2), Widget, Icon Studio, Icon Packs (×2), Localization, Build & Run, Ship
  (×2), Publish, Terminal, New Plugin and Manifest pages, all deep-linked into the
  embedded docs browser (and the offline snapshot).

## Planned

- 📋 **Settings migrations (MD2) editor** and **device/layout scaffolding**.
- 📋 **macOS/Linux shells** - Avalonia port of the shell (Core/CodeGen already portable).

## Engineering rules (unchanged)

1. Generated projects stay 100% stock Macro Deck template; DeckForge state lives in
   `.deckforge/`.
2. The `macrodeck-plugin` CLI is authoritative; DeckForge adds UX, never reimplements.
3. Every documented rule we encode gets a unit test next to it.
4. The SDK version pin lives in `MacroDeckSdkInfo` (bump on Macro Deck releases).
